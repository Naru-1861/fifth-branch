# fifth-branch

첩방단 문진 — 열두 설화 중 다섯 번째(辰), 심청전 덱의 웹 문진.

첩 스물두 장에 구름을 새기면 점수가 매겨지고, 점수에 맞는 방(밀운방·산운방·잔운방)의 카드와 자리 배치가 열린다. 단(실물 카드)은 화면 밖에서 펼친다.

## 구조

| 경로 | 내용 |
|---|---|
| `index.html` | 첫 주소. `/1/`로 넘긴다 |
| `1/index.html` | 1판 문진. 한 파일 안에 DECK·ENGINE·SCREENS가 나뉘어 있다 |
| `1/img/` | 방 카드 앞면·뒷면 (WebP, 가로 720px) |
| `check/check.js` | 판정 자동 점검 |
| `licenses/` | 페이지에 넣은 글꼴의 라이선스 |

판마다 폴더를 둔다. 2판이 생기면 `2/`를 만들고, 인쇄된 QR은 `/1/`을 계속 가리킨다.

## 고칠 곳

`1/index.html` 안에서 지시의 종류마다 고칠 곳이 정해져 있다.

| 바꿀 것 | 위치 |
|---|---|
| 첩 문항, 척도, 방 경계, 방 문안, 카드 그림 | 스크립트의 `DECK` |
| 색, 글꼴, 글자 크기 | `<style>` 맨 위 `:root` 토큰 |
| 화면 배치 | 스크립트의 `VIEWS` |
| 점수 합산, 방 판정 | `/*ENGINE-START*/` ~ `/*ENGINE-END*/` (거의 고치지 않음) |

인쇄된 문안은 인쇄 뒤 화면에서 따로 바꾸지 않는다.

## 판정 규칙 (1판)

- 첩 22문항, 구름 다섯 개. k번째 구름을 누르면 k점. 합계 22–110점.
- 방 경계는 첩 인쇄본 표기를 따른다: 00–30 밀운방(5장), 31–70 산운방(3장), 71–110 잔운방(2장).
- 경계는 응답이 모이면 보정한다.

## 점검

```
node check/check.js
```

- 22–110 모든 총점이 방 하나에만 들어가는지(빈틈·겹침 없음)
- 최저·최고·경계값(30/31, 70/71) 판정
- 무작위 응답 1,000회와 균등 응답일 때의 방 확률

`main`은 보호되어 있다. 모든 변경은 브랜치 → PR → 합치기로 들어가고, 합치기가 곧 배포 승인이다.
