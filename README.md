# 나루슈퍼 (시범판)

무던함 카드 진시 덱의 웹 공간입니다. 까치(방문자)는 오늘의 카드를 하루에 한 장, 까마귀(입장코드를 받은 후원자)는 주인 아주머니를 통해 진시 문진까지 씁니다.
인쇄된 QR이 가리키는 정식 주소가 아닙니다. 정식 주소는 도메인을 연 뒤 정합니다.

- 나루슈퍼: `index.html` (3D 마을, 입장, 오늘의 카드)
- 진시 문진: `jinsi/index.html` (나루슈퍼 안에서만 열림, 직접 열면 닫힌 문)
- 그림: `jinsi/img/`
- 입장코드와 하루 한 장 제한은 브라우저 안에서만 확인하는 시범 수준입니다.
